# Charles Chalimba — Portfolio

A responsive portfolio built with Next.js, TypeScript, and Lucide icons.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm start
```

Edit content in `app/page.tsx`, styling in `app/globals.css`, and page metadata in `app/layout.tsx`. Fonts load from Google Fonts with local fallbacks. All navigation links point to portfolio sections; add verified contact and social links when available.
